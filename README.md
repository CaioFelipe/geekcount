# Geek Friends — Contagem Regressiva | UNEGEEK XP

Página oficial de contagem regressiva para o evento **Geek Friends**, realizado pelo **UNEGEEK XP** — projeto de extensão universitária da **UNEMAT — Campus Sinop**.

- **Data e horário:** 5 de dezembro de 2026 às 16h (`UTC-4`, horário de Mato Grosso)
- **Instagram oficial:** https://www.instagram.com/unegeekxp/

## Como executar localmente

```bash
npm install
npm run dev
```

Para gerar o build de produção:

```bash
npm run build
```
